# 0DTE SPX 定价：三周数据总结与参数建议（2026-11-02 至 11-19）

数据：CBOE 延迟报价，SPXW 当天到期、现价 ±3% 以内，14 个交易日、每天 7–9 个快照，虚值期权报价 9962 个，可组成 10388 个信用价差。11/20 全天 CBOE 网站拒绝访问（Cloudflare 403），没有采到数据。
定价：main 上的 `ZeroDteOptionPricer`（到期 16:00，252×390 分钟，利率 0，股息 0），sigma = VIX/100 × M × (1 + skew × 虚值%)，虚值% = |K/S − 1| × 100。
验证方法：逐日留一（用其余 13 天拟合参数，在剩下一天上检验，14 天轮流），表里的数字都是"样本外"的。
±20% 命中率：期权只统计中间价 ≥ 0.50 的，价差只统计中间价 ≥ 0.20 的。

## 结论和建议

1. **建议打开 skew：M = 0.57，skew = 0.18。** 这是只用 VIX 时最好的模型，样本外 RMSE 1.70（固定倍数 1.80），期权 ±20% 命中率 25%（固定 21%），价差 38%（固定 35%），平均偏差约为 0。和第一周的建议值（0.59 / 0.21）很接近，参数比较稳定。
2. **如果不用 skew，把 ivMultiplier 从 0.65 改成 0.62。** 14 天合并最佳值是 0.62。0.65 在全部数据上 RMSE 1.78，0.62 是 1.72，差别不大，所以 0.65 也可以接受。
3. **不建议用五时段倍数。** 14 天样本外 RMSE 1.81，和固定倍数（1.80）一样，没有改善。五个时段拟合出来的值是 0.65 / 0.61 / 0.56 / 0.57 / 0.62，差别比天与天之间的差别小。
4. **VIX1D 比 VIX 好得多，值得在回测里试。** 在有 VIX1D 的 9 天（11/09–11/19）上，sigma = VIX1D/100 × 0.80 的样本外 RMSE 是 1.33，同样 9 天用 VIX × 0.60 是 1.68，误差降低约 20%；加 skew（0.74 / 0.18）是 1.25，VIX 加 skew 是 1.57。改善最大的是 11/19 大跌日（3.28 → 1.81），但 11/17 反而变差（1.05 → 1.86）。CBOE 有 VIX1D 的历史数据可以下载，如果回测能拿到，建议加一个"波动率来源"配置，可选 VIX 或 VIX1D。
5. **只用指数达不到 ±20% 目标。** 最好的模型期权命中率也只有 25–29%，价差 38%。主要原因是 0DTE 平值 IV 和 VIX 的比例每天变化很大（0.7 到 2.5 倍），VIX 本身看不出来。
6. **大跌日模型会明显低估。** 11/05 和 11/19 当天最佳倍数是 0.82 和 0.76，用 0.62 会低估权利金和价差涨幅。止损类规则要留余量。

## 程序修改建议

1. 默认参数改成 ivMultiplier = 0.57、skew = 0.18。如果暂时不想用 skew，就把 ivMultiplier 改成 0.62。
2. 不做时段倍数。
3. 可选：加一个波动率来源配置（VIX 或 VIX1D）。用 VIX1D 时建议 ivMultiplier = 0.74、skew = 0.18。VIX1D 只有 9 天数据，建议以后再多验证。
4. 回测报告里注明：只用指数时期权价格误差通常超过 ±20%，大跌日会明显低估。
